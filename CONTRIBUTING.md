# Contributing to OpenRelief 🌍

Thank you for your interest in improving OpenRelief!

Our goal is to make resource allocation planning more transparent, accessible, and useful for communities around the world.

## Ways to contribute

You can help by:

- Reporting bugs or suggesting improvements.
- Testing allocation scenarios.
- Improving documentation.
- Proposing fairer allocation methods.
- Improving accessibility and usability.
- Contributing code or tests.
- Suggesting ways to support different resource types.

## Getting started

1. Fork the repository on GitHub.
2. Clone your fork.
3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

5. Test your changes before submitting them.

## Before submitting a change

- Explain the problem your change addresses.
- Keep changes focused and understandable.
- Include tests for new allocation behaviour where possible.
- Never commit private recipient information or sensitive community records.
- Document limitations and assumptions honestly.

## Our principles

OpenRelief aims to support human decision-making, not replace it.

Contributions should prioritise:

- Transparency
- Fairness
- Accessibility
- Privacy
- Responsible use of community data

Allocation recommendations should be explainable and open to human review.

## Submitting contributions

Open an issue to discuss a substantial proposed change before starting work.

When ready, submit a pull request describing what you changed, why it matters, and how you tested it.

Thank you for helping make resource allocation planning more accessible!
